# Contributor Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) Code of Conduct v2.1.

Please read the full text at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

If you experience or witness unacceptable behavior, please report it by opening an issue or contacting the maintainers directly.

## Scope

This Code of Conduct applies within all project spaces and when an individual is representing the project in public spaces.
